# Colour mod (personality-based hue/saturation/value rotation)

Every Pokemon is recoloured from its **personality value (PID)**:

| PID bits | meaning | range |
|---|---|---|
| 0-9   | hue shift        | `bits * 360 / 1024` degrees |
| 10-14 | saturation scale | 70% .. 130% |
| 15-19 | value scale      | 85% .. 115% |

The conversion is `RotateColorHue_HGSS` (RGB555 -> HSV -> shift -> RGB555) in `src/pokepic.c`;
`PersonalityRotatePalette(palette, count, personality)` rotates colours 1..count-1 (index 0 is transparency).

## Where it is applied

| Place | Files |
|---|---|
| 2D sprites (everything that builds a `PokepicTemplate`) | `src/pokepic.c`, `include/pokepic.h`, `src/pokemon.c` (personality propagated in `GetMonSpriteCharAndPlttNarcIdsEx` and the `DP_` variant) |
| Palette loader used by sprites/box/trade | `src/gf_gfx_loader.c` (`GfGfxLoader_GXLoadPalRotated`), `include/gf_gfx_loader.h` |
| Battle send-out + attack animation temp sprites | `asm/overlay_07.s` (`Pokepic_RotateBattlePalette`) |
| Summary/status screen, PC box preview | `asm/overlay_14.s` |
| Trade linking-station preview, trade slide-past silhouette | `asm/overlay_65.s`, `asm/overlay_71.s` |
| Starter selection screen | `src/choose_starter_app.c` |
| Overworld follower (3D model palette, normal + shiny) | `src/follow_mon.c`, `include/follow_mon.h`, `asm/overlay_01_021F944C.s` (model-loaded hook), `asm/overlay_01_021F72DC.s` (per-frame refresh hooks), `src/field_use_item.c` (re-apply on bicycle mount/dismount) |
| Day Care pen Pokemon | `src/scrcmd_daycare.c` |
| NPC trainer Pokemon get random PIDs (so they have varied colours) | `src/trainer_data.c` |
| Gender without ROM reads (follower hot path) | `include/species_gender_ratios_table.h` (generated by `tools/gen_species_gender_ratios.py`) |

`asm/include/*.inc` files only gain `.public` declarations for the new functions.

## Porting it

Copy the files above (or cherry-pick this commit). The follower code must never allocate or read the ROM per frame -
that was the cause of black-screen crashes on hardware - so keep the cached/pre-rotated palette design.

`tools/compare_follower_colors.py` compares a follower model's palette with its 2D sprite palette, to spot species whose
3D model colours differ from the sprite.
